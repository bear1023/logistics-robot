## 集成板 3.1 的真实内容

- 2 × 25P 母座（`ZX-PM2.54-2-25PY`），用来插 STM32F407 核心板/开发板；
- XH2.54（4/8/10/12/14P）、PH2.0、DC-005 电源座 ×4、船型开关 `SS11-RBIWG-R20-R`、拨动开关 `SS-12D10L5`、`KF301-5.0-2P` 端子、0805 电阻与 LED；
- **板上没有任何 IC**（无 DCDC、无 LDO、无电机驱动）——电源与驱动都是外购模块，通过端子和母座连过来。

也就是说：这块板是"接线底板"，核心板插上去、模块用线拧上去，不是完整的主控板。

## 电源网络

工程里出现过的网络名：`12V`、`12V0`、`12V5`、`12V6`、`8.4V`、`5V`、`5V1`、`VCC3.3`、`VBAT`。

对应关系（按用途推断，未经测量确认）：

| 网络 | 用途 |
| --- | --- |
| 12V / 12V0 / 12V5 / 12V6 | 电池与步进驱动供电 |
| 8.4V | 云台舵机（`servo.c` 注释） |
| 5V / 5V1 | 树莓派、摄像头 |
| VCC3.3 | MCU、OLED、IMU |
| VBAT | 电池检测/备用 |
