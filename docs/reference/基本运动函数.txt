基本移动函数：
void car_move2(float x,float y,int a_in,int car_speed)
说明：实现左右方向的移动； 如果x>0 小车左移
相匹配的函数：void car_move4(float x,float y,int a_in,int car_speed) //仅仅移动，不延时 
/*	
	float x ：移动的距离（x轴）左右移动的距离
	float y ：移动的距离（y轴）一般直接给0
	int a_in : 移动的加速度    可取的范围 150rpm/s到200rpm/s
	int car_speed : 移动的速度  可取的范围 150rpm 到 200rpm
*/

void car_move1(float x,float y,int a_in,int car_speed)
说明：实现前后方向的移动； 如果y>0 小车前进
相匹配的函数：void car_move3(float x,float y,int a_in,int car_speed) //仅仅移动，不延时 
/*	
	float x ：移动的距离（x轴）一般直接给0
	float y ：移动的距离（y轴）前后移动的距离
	int a_in : 移动的加速度    可取的范围 150rpm/s到200rpm/s
	int car_speed : 移动的速度  可取的范围 150rpm 到 200rpm
*/
