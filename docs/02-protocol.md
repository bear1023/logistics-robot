# 通信协议

## 1. CAN：Emm_V5 闭环步进

### 1.1 物理层与链路参数

| 项 | 值 |
| --- | --- |
| 外设 | CAN1 |
| 波特率 | 500 kbps（APB1 42 MHz，Prescaler 7，BS1 9 tq，BS2 2 tq，SJW 1 tq） |
| 引脚 | PA12 = TX，PA11 = RX |
| 过滤器 | 32 位掩码，ID 与掩码均 `0x00`（全通过） |
| 接收 | `CAN1_RX0` 中断只置 `rxFrameFlag`（当前无人读取） |

### 1.2 帧格式

```
ID  : 扩展帧，ExtId = (电机地址 << 8) | 包序号
Data: [0] 功能码，[1..] 参数，>7 字节按 7 字节分包
末字节固定 0x6B（校验/结束标志）
```

电机地址分配：

| 地址 | 用途 |
| --- | --- |
| 1–4 | 四个轮子 |
| 5 | 升降（80 脉冲/mm） |
| 6 | 平推（25.465 脉冲/mm） |
| 0x00 | 广播（用于同步启动 `0xFF`） |

### 1.3 功能码

| 码 | 含义 | 说明 |
| --- | --- | --- |
| `0x0A` | 清零位置 | — |
| `0x0E` | 解除堵转保护 | — |
| `0x31` `0x33` `0x35` `0x36` `0x37` `0x3A` `0x3B` | 读参数 | 细分、最大电流、位置等 |
| `0x42` `0x43` | 读状态 | — |
| `0x46` | 切换控制模式 | 通讯/脉冲/IO 模式 |
| `0xF3` | 使能 | 上电后必须先使能 |
| `0xF6` | 速度模式 | 参数：速度、加速度 |
| `0xFD` | 位置模式 | 参数：方向、速度、加速度、脉冲数、相对/绝对标志 |
| `0xFE` | 急停 | — |
| `0xFF` | 同步启动 | 广播给所有地址，让多轴同时动 |
| `0x93` `0x4C` `0x9A` `0x9C` | 回零 | — |

> 完整寄存器级说明见张大头官方 `Emm_V5` 手册；本仓库的 `can_ZDT/Emm_V5.c` 是厂商例程，调用封装在 `yyb_move.c` 里。

## 2. 树莓派串口（USART1 @ 9600 8N1）

### 2.1 命令（MCU → Pi，单字节 ASCII）

| 码 | 含义 |
| --- | --- |
| `1` | 扫二维码 |
| `2` | 圆盘定标（第 1 圈） |
| `3` | 识别待抓的 3 块（第 1 轮） |
| `4` | 识别待抓的 3 块（第 2 轮） |
| `5` / `6` | 抓第 2 / 3 块确认 |
| `7` | 色环粗定位（**省赛为 `5`**） |
| `8` | 色环精定位（**省赛为 `6`**） |
| `9` | 码垛粗定位 |
| `0` | 码垛精定位 |
| `a` | 圆盘定标（第 2 圈） |
| `b` / `c` | 抓第 2 / 3 块（第 2 圈） |
| `d` | 直线角度纠偏（国赛新增） |
| `r` | 重启树莓派 / 发任务码 |

### 2.2 回帧（Pi → MCU，11 字节）

```
0xFF | 9 字节 ASCII | 0xFE
```

| 类型 | 9 字节内容 | 解析方式 |
| --- | --- | --- |
| 坐标 | `xxxx yyyy c` | 4 位 x + 空格 + 4 位 y + 空格 + 1 位颜色 |
| 角度 | `000000±nn.n` | `[7]` 符号，`[8]` 整数，`[10]` 小数 |
| 任务码 | `123+312` + 填充 | 字符串 |
| 就绪 | `987654321` | 全部相等即就绪 |
| 省赛 ACK | `123456789` | 递增序列 |
| 未识别 | `000000004` | `[8]=='4'` → 重试 |

颜色码：`1` 红、`2` 绿、`3` 蓝、`4` 无。

**没有校验、没有长度字段**，只靠 `0xFF`/`0xFE` 定界。`wait_send_shumeipai()` 的 `time` 形参未使用，所以**没有超时重发**。

## 3. 串口屏（陶晶驰 TJC，USART6 @9600）

文本控件赋值 + 三字节帧尾：

```c
HMISendStr("t0.txt=\"%d\"", value);   // 内部拼成 t0.txt="123" + 0xFF 0xFF 0xFF
```

用途：现场显示坐标、颜色、当前步骤，便于不接电脑调试。

## 4. 蓝牙（HC-05，UART5 @9600）

AT 模式配置（`usart5.c`）：

```
AT+NAME=mousecar       // 改名字
AT+PSWD=1234           // 配对码
AT+ROLE=1              // 主/从
AT+BIND=98:DA:20:07:6D:F5
```

用途：现场手动干预/查看状态，不参与自动流程。

## 5. IMU（WIT，UART2 @115200）

- 协议：`WIT_PROTOCOL_NORMAL`，`WitInit(WIT_PROTOCOL_NORMAL, 0x50)`
- 只取 Yaw（`fAngle[2]`，寄存器 `0x3f`），加速度/角速度读了但没进控制
- 解锁寄存器写：`KEY=0x69`、`KEY_UNLOCK=0xB588`；`WitWriteReg(0x76, 0x00)` 清 Yaw 零点

## 6. 上电时序（容易踩的坑）

```
MCU 上电 → 等树莓派发 "98"（无超时，死等）
        → 等 PC9 开关闭合
        → 开始自动流程
```

树莓派没起来 / 串口线没接 / 波特率不对 → 整车停在初始化，现象是"屏上没有任何反应"。现场排查第一步就是看树莓派有没有发 `98`。
